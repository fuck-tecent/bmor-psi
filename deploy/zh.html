    ∀ 偶数 n ≥ 4，是否总存在素数 p, q 使 n = p + q ？

    数值验算终有尽头——这便是自 1742 年悬而未决的强哥德巴赫猜想。

    1. 1957–1973

      从华罗庚的一本书，到陈景润的「1 + 2」

      华罗庚在《堆垒素数论》中研究怎样用素数及其幂的和表示整数。年轻的陈景润在厦门读这本书时，为其中的「塔内问题」写出了改进。华罗庚读到论文后推荐了他。1957 年，陈景润进入中国科学院数学研究所。

      到了 1966 年，陈景润宣布「1 + 2」，并在 1973 年发表详证。每个充分大的偶数都能拆成一个素数，加上一个素数或两个素数的乘积。要从这里走到「1 + 1」，还得证明总能选到第二个加数本身也是素数的那种拆法。

      中科院人物史料陈景润 1973 年论文

    2. 1979.10

      1979 年的英国讲座

      清华大学校史馆记载，伯明翰大学的演讲在 1979 年 10 月 8 日举行，题目是《为百万人的数学》。华罗庚的助手计雷在回忆文章里把英国讲座的海报题名记作《百万人的数学》。他也写到了数学怎样走进日常工作。在山西大同，团队运用统筹法，帮运煤车站解决了机车上水、除灰、加煤都要排队的问题。这样的工作做了近二十年。

      清华大学校史馆 · 演讲记录中科院 · 计雷《追忆华罗庚老师》

    3. 2026.08

      黎曼猜想帮我们把范围缩到多小？

      黎曼 ζ 函数的零点告诉我们，素数的实际个数能偏离预测多少。狄利克雷 L 函数的广义黎曼猜想（GRH）还让我们按除以某个数所得的余数，分别估计各类素数的个数。

      2026 年 8 月，Chirre 和 Hagen 给出了一个具体的界。在黎曼猜想成立的条件下，对每个 x ≥ 2，区间 (x, x + 123(ln x)²] 里至少有一个偶数是两个素数之和。现在把手指按在区间里某个指定的偶数 N 上。要为它找到一对，还得证明至少有一个素数 p 使 N − p 也恰好是素数。这正是研究台要估计的配对数。

      短区间论文 · 定理 1看素数配对的研究任务

    近期进展与原文

    1. 2026.11.21

      黎曼猜想的 Lean 证明通过了哪些核验？

      莱文特·阿尔波格于 11 月 20 日公开了与 Claude 合作完成的形式化证明。次日，Lean 与 Mathlib 社区发表声明，确认所核验的命题与 Mathlib 的黎曼猜想定义一致，证明通过了多个检查器。

      澎湃新闻报道社区核验声明MIT 核验记录

    2. 2026.11.13

      一条通向强哥德巴赫猜想的条件性路线

      山东大学公布了李嘉旻、刘建亚的论文。作者给出的条件是狄利克雷 GRH 成立，并且文中两种关于谱的额外假设至少有一种成立。在这些前提下，每个充分大的偶数都有素数对表示。证明其中一个额外假设，仍是这条路线上的难题。

      山东大学 · 中文摘要作者论文（PDF）

    3. 2026.06.01

      从「1 + 2」细化到「1 + 1.9」

      对每个充分大的偶数 N，李嘉旻、刘建亚的预印本给出分解 N = p + rq，其中 p、q 为素数，r 为 1 或素数。他们把较小因子的大小限制为 r ≤ q0.9。取到 r = 1 时，式子就成为两个素数之和。

      arXiv 预印本厦门大学讲座报道

    提交一份证明

    人工和 AI 都可以参与。选择一条待证引理，在指定文件中证明已发布的 Lean 命题，然后提交单文件 PR。

    阅读贡献指南 ↗ 打开 GitHub 仓库 ↗

    参与流程

    1. 领取一条引理

      研究台分配一条可领取的引理，提供固定的 Lean 命题和有时限的任务凭证。

    2. 证明并提交

      在指定文件编写证明，创建只包含该文件的 PR，并向研究台登记。

    3. 跟进 Lean 验证

      在 PR 中请求权威验证，在验证日志中查看运行和判定。
