## 一　用算术动力系统与齐次动力系统约化二元哥德巴赫问题

### 新路线 · 加法轨道上连续二进区间的反射

取同一个充分大的偶数 $n$，$w(t)=\mathbf1_{\mathbb P}(t)\log t$，$w(0)=0$。令 $k=\lfloor\log_2n\rfloor$，$H=2^{k-\lfloor k/4\rfloor}$，$a_0=2\lceil n/4\rceil$，$B=\lfloor n/(8H)\rfloor$。把 $I=[a_0,a_0+BH)\cap\mathbb Z$ 分成 $B$ 个长 $H$ 的整块。$I,n-I$ 都在中央三分区间，$|I|=n/8+O(H)$。加法映射 $x\mapsto x+1$ 与反射 $x\mapsto n-x$ 将这两段轨道按相反顺序配对。当 $n=2^k,\ k\ge12$ 时，块起点、$H,B$ 恰与 `dyadic-cell-reflected-cancellation` 相同。第三批 `dyadic-carry-telescope` 使用模 $2^j$ 的余类，此处的子块是相邻的整数。[原题及已证的短素数下界、块合成][cat]

对齐每个整块，逐次对半分。记 $\Delta_J a$ 为左半块的和减右半块的和，$a(x)=w(x), b(x)=w(n-x)$。记 $P(a,b)=\sum_{\text{整块 }K}(\sum_K a)(\sum_K b)/H$，$T_\mathcal L(a,b)=\sum_{J:\,|J|\in\mathcal L}\Delta_J a\,\Delta_J b/|J|$，$R_I=\sum_{x\in I}a(x)b(x)$。所有子块都取半开区间。$Y=(\log(2n))^6$。取 $g(x)=(30/8)\mathbf1_{(x,30)=1}$、$d=w-g$、$d^R(x)=d(n-x)$。

### 新路线 · 闭极限圆的 Farey 截面与两侧半素数的重叠

bases = (17, 19, 23, 181, 29, 37, 41, 43, 31, 47, 53, 67)
wheel, limit, length = 30030, 100000, 16384
extra = list(primerange(17, 857))
digest = sha256()
for base in bases:
    keep = bytearray([1]) * (limit + 1)
    for prime in primerange(17, isqrt(base + wheel * limit) + 1):
        start = (-base * pow(wheel, -1, prime)) % prime
        if base + wheel * start == prime:
            start += prime
        if start <= limit:
            keep[start::prime] = bytes(1 + (limit - start) // prime)
    row = [base + wheel * k for k, flag in enumerate(keep) if flag][:length]
    assert len(row) == length and row[-1] <= 1926574681
    loss = sum(max(Counter(p % q for p in row).values()) for q in extra)
    assert loss <= 16283
    digest.update((" ".join(map(str, row)) + "\n").encode("ascii"))
assert digest.hexdigest() == "22ecf2d009b4f3d6ad709240a8f4b8275b84517aa71162483d54faa5f5b4a995"
~~~

def rfc11On (lo hi : ℕ) : Prop := ∀ n : ℕ,
  lo ≤ n → n < hi → 2 ∣ n →
  ∃ p q : ℕ, Nat.Prime p ∧ Nat.Prime q ∧ p + q = n

def rfc11Dyadic (cap j : ℕ) : Prop :=
  rfc11On (2 ^ j) (min (2 ^ (j + 1)) cap)

abbrev rfc11Band (j : ℕ) : Prop := rfc11Dyadic (10 ^ 180) j

### 4.2　新路线 · 用模 210 的谱分解倒算逐点误差预算

本节只需研究 $C<n<T$ 的偶数。固定第 4.1 节中包含 $n$ 的计算子段 $[L,U)$，令 $Q=210,\ \varphi(Q)=48,\ K=Q/48=35/8$。在循环群 $\mathbb Z/M\mathbb Z$ 上取 $M=Q\lceil(2U+1)/Q\rceil$，标准代表取 $0,\ldots,M-1$。令 $a(t)=\log t$ 当且仅当 $1\le t<U$、$t$ 是与 $Q$ 互素的素数，其余为零。$b(t)=K$ 当且仅当 $1\le t<U$ 且 $(t,Q)=1$，其余为零。置 $d=a-b$。此处卷积用未归一化整数和，DFT 用 $\widehat d(k)=\sum_t d(t)e(-kt/M)$、$e(u)=e^{2\pi iu}$。$M>2U$ 消除回绕，$(a*a)(n)>0$ 即可用已验收的 `prime-weight-extraction` 取得真素数对。[固定进程估计的来源][r11-bmor] · [已有谱与余类任务][r11-cat]

from functools import lru_cache
from math import gcd

def cm_add(P, Q, m):
    if P is None:
        return Q
    if Q is None:
        return P
    x, y = P
    u, v = Q
    if x == u and (y+v) % m == 0:
        return None
    if P == Q:
        numerator, denominator = 3*x*x - 1, 2*y
    else:
        numerator, denominator = v-y, u-x
    slope = numerator * pow(denominator, -1, m) % m
    z = (slope*slope - x - u) % m
    return z, (slope*(x-z) - y) % m

def cm_mul(scalar, P, m):
    result = None
    while scalar:
        if scalar % 2:
            result = cm_add(result, P, m)
        scalar //= 2
        if scalar:
            P = cm_add(P, P, m)
    return result

@lru_cache(maxsize=None)

    assert cm_add(point, point, m) is None
    order = 1 << 301
    J = order**2 + 6*order + 1 - m

    return m

**固定分母的组合条件。** K08 需要每个充分大偶分母有 $H_N\ge cN^{1/10}$。K10 给总数，K11 可给一部分分母，尚缺逐窗主量及剩余分母的下界。K09 需要 K12、K13 对相同分母同时成立且 $a_K+b_K\le1$，其结论是粗筛的余项界。K08、K09 各自只描述这条轨道上的一个输入。

K01 所述的二维线性限制与 K05 的有限商扩张可以同时成立。前者固定和后作用在一条直线上，后者允许分母变化。K06 即使给出每个模数的高度窗误差，K07 仍含 $k\ne0$ 的频率。只有控制这些频率在所指定 $N$ 的带相位和，才得到 K08 或 K09 的逐分母结论。[同余半群的高度计数][ad-height] · [生产 Farey 路线][ad-farey]

### 5.4　首端素数、Chen 候选和两条路线的合流

仍固定同一个充分大的偶数 $N$。令 $f_N(u)=\mathbf1_{u\in\mathcal F_N}\,w(u)$，$\Xi_N=\sum_{u\in I}f_N(u)$，$z=N^{1/8}$，$D=\lfloor N^{3/8}\rfloor$。设 $P(z)=\prod_{\ell\le z,\ \ell\ {\rm prime}}\ell$。对平方自由 $d$ 定义 $\gamma_N(d)=1/\varphi(d)$ 当 $(d,N)=1$，否则为 0，且 $\gamma_N(1)=1$。记 $V_N(z)=\prod_{\ell\le z}(1-\gamma_N(\ell))$，只取素数。$N$ 为偶数使其中的 $\ell=2$ 因子等于 1。设 $S_N=\sum_{u}f_N(u)\mathbf1_{(N-u,P(z))=1}$，这是首端已经为素数、补数通过初筛的对数质量。$\omega(d)$ 只计不同素因子，$\Omega(b)$ 按重数计。[仿射筛的算术输入][ad-affine] · [项目现有的粗筛路线][ad-rough]

**Chen 路线各组合指标的验收条件。** W01 需要每个充分大偶分母有 $\Xi_N\ge c_1H_N$，W07、W08 先给同一高度窗的输入，单个分母的质量下界仍待取得。W02 的首端分布预算在 $a_W+b_W\le1$ 且 W09、W10 的估计逐分母同时有效时成立。W04 的坏质量上界取 $\beta=\beta_{\rm eq}+\beta_{\rm dist}$，其中 $\beta_{\rm eq}$ 还须由 W11 的实际平方模数和除以 $\Xi_NV_N(z)$ 得到可证上界，W12 供应另一项。W06 取 $b_1=b_m+b_t$。接到下式需 W03 的 $\alpha$、W05 的 $b_0$ 及 $b_0+b_m+b_t<\alpha-\beta$，并在同一个 $N$ 上证明 $\Xi_N>0$。

令 $D_C=\sum_u f_N(u)c(N-u)$，$J=\sum_u f_N(u)g(N-u)$。W03、W04 给 $D_C\ge(\alpha-\beta)\Xi_NV_N(z)$。此处 $\Xi_N>0$ 由 K08、W01 保证，$V_N(z)>0$ 由局部因子给出。W05、W06 给 $J=J_0+J_1\le(b_0+b_1)\Xi_NV_N(z)$。平台的 `finite-weighted-liouville-selector` 直接给出

$$
D_C-J=2\sum_{\substack{u\in\mathcal F_N,\ u,\ N-u\ {\rm prime}\\(N-u,P(z))=1}}\log u>0 .
$$

因此得到同一个 $N$ 的两个真素数，再用 `log-correlation-iff` 得 $R(N)>0$。W03、W04 单独完成时只能在本轨道得到首端为素数、补数至多有两个素因子的候选。现有 Chen $1+2$ 定理若用于此处，还需证明可选到满足 K02 数字条件的分子。K02 的单射使这里的 $\log u$ 权已经按不同分子计数。[已验收的带权奇偶恒等式][ad-cat] · [原提案的两种合流](arithmetic_dynamics_spectral_correlation_workbench_note.md)

### 5.5　有限复核、派发次序与最终阈值

对 $4\le N\le2048$ 的 1,023 个偶数，用半群递推枚举全部轨道列，并独立用欧几里得算法对每个 $1\le u<N$ 核验成员资格。所有分母不分奇偶一共 17,972 列，偶分母上共有 5,986 列。**31 个偶分母的纤维为空，793 个偶分母有轨道内的 $1+P_2$ 表示，其中 529 个有轨道内的双素数表示。** 在 $1024\le N\le2048$ 的 513 个偶数上，513 个纤维全都非空，450 个有 $1+P_2$，309 个有双素数。例子 $N=210$ 在该模型中纤维为空，但 $210=11+199$。$N=1024$ 有八个合格分子，其中没有一对给出两个素数，但 $1024=3+1021$。这些差别决定 K08、W01 和 W06 必须分别验收。[有界部分商的分母问题][ad-zaremba]

以下代码可复算上述计数。见证表按 $N$、$u$ 升序，以 ASCII `N,u\n` 逐行作 SHA-256。对 $d=2,3,4,5,6,7,8,9,10,15,21,30,35,42,105$，还独立从种子广度遍历模商，并与所有本原列逐列比较。模 105 的整轨道恰有 9,216 列，取整数分母 210 时却没有轨道点。

~~~python
from hashlib import sha256
from math import isqrt

limit = 2048
fibers = [set() for _ in range(limit + 1)]
stack = [(2, 3)]
while stack:
    u, n = stack.pop()
    assert u not in fibers[n]
    fibers[n].add(u)
    for a in range(1, 6):
        for b in range(1, 6):
            v = u + b*n
            height = a*v + n
            if height <= limit:
                stack.append((v, height))

def from_digits(u, n):
    digits = []
    while u:
        digit, rem = divmod(n, u)
        if digit > 5:
            return False
        digits.append(digit)
        n, u = u, rem
    return n == 1 and len(digits) % 2 == 0 and digits[-2:] == [1, 2]

def factor_count(n):
    count = 0
    for p in range(2, isqrt(n) + 1):
        while n % p == 0:
            n //= p
            count += 1
    return count + (n > 1)

big_omega = [0, 0] + [factor_count(n) for n in range(2, limit + 1)]
for n in range(2, limit + 1):
    assert fibers[n] == {u for u in range(1, n) if from_digits(u, n)}

def census(start):
    even = range(start, limit + 1, 2)
    empty = sum(not fibers[n] for n in even)
    chen = sum(any(big_omega[u] == 1 and 1 <= big_omega[n-u] <= 2 for u in fibers[n]) for n in even)
    goldbach = sum(any(big_omega[u] == big_omega[n-u] == 1 for u in fibers[n]) for n in even)
    return len(even), sum(len(fibers[n]) for n in even), empty, chen, goldbach

assert sum(map(len, fibers)) == 17972
assert census(4) == (1023, 5986, 31, 793, 529)
assert census(1024) == (513, 4123, 0, 450, 309)
data = "".join(f"{n},{u}\n" for n, fiber in enumerate(fibers) for u in sorted(fiber))
assert sha256(data.encode("ascii")).hexdigest() == (
    "e64aad7eb214f067a102b4defddb5c64d97ea1b0dad1f5d33f4351ff1d0c9666")
~~~

**派发顺序。** AD01、AD02 给层增量的共同定义。AD07–AD10 各自核算可证的层或间距。K02、K03 接 K10 的偶分母计数，K07 接 K12、K13 的分模数估计。首端素数加权后的 W07–W10 各用相应的实际测度。W11、W12 可分别处理平方模数与不同因子的损失，W13、W14 估带符号的中间层与末层。$\alpha,\beta,b_0,b_1$ 只在支持、权和起点一致时交给已有的选择引理。[提案的首批建议](arithmetic_dynamics_spectral_correlation_workbench_note.md)

**终点。** 路线 I 若已兑现 AD04 对真实进程和的误差界，可在其起点、AD05 与 AD06 的起点及 $2^{60}$ 四者的最大值处接出真实 $R(N)>0$。仿射路线可以仅复用 AD02 的恒等式，由自己的 K08、W01–W06 取得同一结论。两条路线择一给出数值 $N_*$ 后，用已有 `threshold-coverage` 对 $4\le N<N_*$ 的每个偶数接有限证明，$N=N_*$ 归大偶数侧。第四章以 $10^{316}$ 为上限的 823 段只在已经取得全段证明或具体见证的子域交接。若尚有未覆盖偶数或尚未量化的起点，整题继续开放。正式 Lean 声明须写出所用解析假设、输入和阈值，证明状态以平台独立回放为准。[冻结的真素数正性目标与阈值桥][ad-cat]
